So funktioniert's

Vom Ordner voller HTML-Dateien zum Startmenü

01

Hinzufügen

Datei auswählen oder ins Fenster ziehen. Der Name kommt aus dem <title> der Seite, lässt sich aber jederzeit ändern.

02

Merken

Die Liste bleibt gespeichert – auch nach einem Neustart. Jedes Programm behält seinen eigenen localStorage, unabhängig von den anderen.

03

Starten

Klick auf die Karte, oder direkt die Datei doppelklicken – beides öffnet sofort im Vollbild, ganz ohne Browser-Chrome.

Details

Für Dateien, die sich wie Programme anfühlen sollen

Doppelklick startet direkt

Eine Datei per „Öffnen mit“ starten, öffnet sie sofort im Vollbild – kein Menü im Weg. Nur das Programm selbst öffnen zeigt die Übersicht.

Echtes Vollbild

F11 schaltet um, Strg+W beendet, F5 lädt neu, F12 öffnet die Entwicklertools. Esc bleibt bewusst dem Programm überlassen, für Pausemenüs.

Getrennter Speicher

Jedes Programm hat seinen eigenen localStorage und IndexedDB. Entfernen und später wieder hinzufügen – der Spielstand bleibt.

Schnell gestartet

Rund 230 ms bis zum ersten Fenster. Der eigentliche Code der App ist 41 KB – der Rest ist die Chromium-Engine, die WebGL und WebGPU mitbringt.

Für Entwickler

Selbst bauen, in einem Befehl

Keine nativen Abhängigkeiten – @electron/packager kopiert nur vorgefertigte Electron-Binaries. Das funktioniert auch für alle drei Systeme aus einem Linux-Container heraus, ganz ohne Node auf dem Host.

Quellcode auf GitHub 
# bauen ohne Docker
git clone https://github.com/erqf1/html-launcher.git
cd html-launcher && npm install
npm run build

# oder per Docker, ganz ohne Node lokal
docker compose run --rm build
