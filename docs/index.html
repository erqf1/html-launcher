So funktioniert's

Doppelklick, fertig

01

Doppelklicken

Datei doppelklicken oder per „Öffnen mit“ starten (nach der Installation steht HTML Launcher dort zur Auswahl) – sie öffnet sofort in ihrem eigenen Fenster.

02

Merken

Ganz nebenbei landet die Datei in einer Liste, die auch einen Neustart übersteht. Jedes Programm behält dabei seinen eigenen localStorage.

03

Übersicht bei Bedarf

HTML Launcher selbst öffnen (ohne Datei) zeigt das Menü mit allem, was du je gestartet hast – zum erneuten Starten, Umbenennen oder Entfernen.

Details

Für Dateien, die sich wie Programme anfühlen sollen

Doppelklick startet direkt

Eine HTML-Datei doppelklicken oder per „Öffnen mit“ starten, öffnet sie sofort – kein Menü im Weg. Nur das Programm HTML Launcher selbst öffnen zeigt die Übersicht.

Vollbild auf Wunsch

Startet standardmäßig als normales, maximiertes Fenster. F11 schaltet ins echte Vollbild, Strg+W beendet, F5 lädt neu. Esc bleibt bewusst dem Programm überlassen, für Pausemenüs.

Getrennter Speicher

Jedes Programm hat seinen eigenen localStorage und IndexedDB. Entfernen und später wieder hinzufügen – der Spielstand bleibt.

Schnell gestartet

Rund 230 ms bis zum ersten Fenster. Der eigentliche Code der App ist rund 40 KB – der Rest ist die Chromium-Engine, die WebGL und WebGPU mitbringt.

Installer oder portabel

Windows und Linux gibt es beide Wege: ein Installer, der HTML Launcher bei „Öffnen mit“ einträgt, oder eine Version ohne Installation zum Mitnehmen.

Apache-2.0, quelloffen

Der komplette Quellcode steht auf GitHub. Ändern, forken, selbst bauen – auch per Docker, ganz ohne Node auf dem eigenen Rechner.

Für Entwickler

Selbst bauen, in einem Befehl

electron-builder erzeugt Installer, portable Version, .deb und .pacman aus demselben Quellcode. Windows- und macOS-Pakete baut eine GitHub-Action auf echten Runnern; .deb/.pacman lassen sich lokal auch per Docker bauen (das Linux-Werkzeug fpm braucht einen Linux-Unterbau).

Quellcode auf GitHub 
# bauen ohne Docker (Windows/macOS)
git clone https://github.com/erqf1/html-launcher.git
cd html-launcher && npm install
npm run build:win

# .deb/.pacman per Docker, ganz ohne Node lokal
docker compose run --rm build
